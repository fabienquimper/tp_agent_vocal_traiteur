# Template Persona — À compléter

Copie ce template et remplis-le pour un 3e persona de ton choix
(par exemple : un client malvoyant, un utilisateur âgé, un utilisateur non francophone).

---

```
┌─────────────────────────────────────────────────────────┐

│  [Métier / Rôle], [Ville]                               │
├─────────────────────────────────────────────────────────┤
│  CONTEXTE                                               │
│  [Décris dans quelle situation il/elle utilise l'app]   │
│  [Quel appareil ? Où ? Quand ?]                         │

│  OBJECTIF PRINCIPAL                                     │

│  • [...]                                                │
│  • [...]                                                │

```

## Prompt IA pour générer un persona

Utilise ce prompt dans Claude ou ChatGPT pour créer un persona rapidement :

```
Génère un persona utilisateur pour une application de chatbot vocal
destinée au site web d'une entreprise de restauration traiteur.

Le persona doit avoir :
- Un prénom, âge, profession réaliste
- Un contexte d'utilisation précis (appareil, lieu, moment)
- Un objectif principal avec l'application
- 3 frustrations avec la solution actuelle (téléphone ou email)
- Une citation directe (ce qu'il/elle dirait)
- 2 implications concrètes pour les choix d'interface

Cible : [décris ici le profil voulu, ex: "une personne âgée peu à l'aise avec la tech"]
```

## Questions de réflexion

Après avoir créé ton persona :

1. **Conflits** : Y a-t-il des besoins contradictoires entre les 3 personas ?
   (Ex : Marc veut beaucoup d'info sur une ligne, Sophie veut de la simplicité)

2. **Priorité** : Si tu devais choisir un seul persona à satisfaire en priorité, lequel ?
   Justifie avec un argument business (qui génère du chiffre d'affaires ?).

3. **Accessibilité** : Un de tes 3 personas a-t-il des besoins d'accessibilité spécifiques ?
   (vision réduite, mobilité réduite, dyslexie...)
   → C'est exactement ce que le RGAA va t'aider à adresser dans le module 06.
